DSL v6 specification (fixed for all inputs):
Types are case-sensitive names inferred from declarations; Int is the integer sort. Other names are uninterpreted nonempty entity sorts (e.g. Person, Award, Event, Place, Proposition). Bool is reserved. Use integer literals, not Int constants. Functions have declared argument types and return Int; use single-valued attributes for birth years, event years and event counts. Predicates return truth values. Declare every symbol used by evidence or claim.
Constants have canonical names, types and alias strings referring to that SAME entity. An alias must not collide with another declaration. Different constant names do NOT automatically imply inequality: explicitly use ne with a source quote for textually distinct people/entities. Do not add global unique-name or closed-domain assumptions. A claim-only entity has no evidence facts unless warranted by the evidence.
Terms: const/var have name; int has value; fun has name and args; add/sub have left and right integer terms. Formulas: pred has name and term args; not has arg; and/or have at least two formula args; implies has left/right formulas; eq/ne/lt/le/gt/ge compare left/right terms; exists/forall have variables (name,type) and body. Variables must be bound, and nested quantifiers must use fresh names. Existential witnesses in separate formulas are independent. All evidence formulas are conjoined. Quantifiers range over open sorts, never just declared constants. A source_quote must be an exact, nonempty, contiguous substring of EVIDENCE; it is provenance, not executable logic.
Represent allegations/denials as predicates about speakers and Proposition entities, without asserting or negating the reported event unless evidence independently warrants it. Represent uncertain reference by disjunction over warranted alternatives. An exhaustive list needs a universally quantified restriction; an open list does not. Only/unique constraints need their full person, award, event and time scope. Again/first/second need prior-occurrence or no-earlier-occurrence constraints when relevant. Keep appointment intervals separate from event years. Claim formulas must preserve the same relations and scopes used in evidence.
For UNSUPPORTED use empty constants, predicates, functions and evidence arrays, null claim, and explanatory notes. For OK supply nonempty evidence and a claim formula. Notes are explanatory only and cannot repair missing formulas. Do not put a verdict in any field.
