# Prompt-v3草案与验证建议

## 当前依据

v2主跑749/885（84.63%），网络恢复后750/885（84.75%），NEI召回71.29%。残余NEI误反120条：相似主体38、指代27、时间预设27、唯一性15、集合封闭6、时间范围5、否认2。集合封闭Accuracy从v1的92.11%降到v2的88.16%；补齐后相对v1仍有21条退步。

## 本草案只改一处

保留v2全部其他文字，包括已取得较好结果的否认规则、任务定义、三项检查、输入位置和最终Verdict格式。仅替换“穷尽子集与限定名单”这一条，要求同时保留限制的强度和作用范围，并核验相容场景不能偷偷改掉原文明示的主体、事件、时间或范围。

目的：测试能否纠正模型过度放宽明确名单/数量限制的问题，同时避免为了贴合金标准而补出原文没有的节目范围。已知Hegseth节目名称缺失的争议样本继续保留原标签评分，不能据此增加无依据的REFUTES规则。该草案不声称能同时解决全部38条相似主体、27条指代或27条时间预设错误。

## 后续顺序与比较口径

先比较v2与这一处规则变化。另行研究指代对齐和事件时间绑定时，各自作为独立改动，不一次混入本草案，否则难以定位收益和回归来源。不要把NEI召回提高本身当作成功，需要同步检查三类Recall、Macro-F1、REFUTES Precision和逐条退步。

优先以新建、人工核验的最小差异样本及不同group的保留数据检验规则；这些样本不能抄写原挑战错例后又当作未见测试。可在旧挑战集上继续做开发比较，但所有885条已经观察，事后划分也不能恢复成未见测试集。900条基础集需补做回归检查，以评估v2和后续版本是否影响基础能力。

本草案尚未调用模型，不预报提升幅度。若后续运行，沿用同一模型、temperature=0、关闭thinking、max_tokens4096与单次判断方式；记录实际token与耗时，避免只看准确率而无限堆叠提示词。对照尽量同期请求，历史主跑与网络补跑分数仍分别保留。
