# v3两次全量复测预案

冻结v3提示词和全部生成参数，按原顺序分两次重新请求885条挑战集，共1770条主跑请求；不复用旧预测，不改提示词、标签或模型。顺序运行，每次并发4。用户要求静默运行，过程写入文件，结束后统一报告。

主跑保留请求失败计分，网络中断检查接口后续跑未完成项；网络失败另存补跑，不按预测正确与否重跑。主结果与恢复结果分别比较。

报告准确率范围、三类Recall、Macro-F1、逐条一致率、反复错例和错误机制。另计算三轮多数票（全异选原轮标签）及至少一轮正确的金标准辅助上限；二者都不是新提示词单次表现。金标准辅助上限不可部署。

同一885条数据重复使用，不能当成1770或2655条独立测试样本。temperature=0的复测反映当前服务/输出稳定性，不能证明提示词可达到90%，也不能证明模型能力上限低于90%。90%至少需要797/885条正确，最终统计与该门槛的距离。旧挑战集已观察，泛化仍需新保留数据验证。
