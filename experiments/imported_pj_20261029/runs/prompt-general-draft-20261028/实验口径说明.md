# 通用提示词实验口径

用户指出主实验应关注同一通用提示词的准确率。本稿仅保留任务定义、只依据证据、逻辑蕴含与缺失信息的统一判定原则；无示例，无人物/家族/奖项/年份/名单/否认等专项规则，无外显分项检查表。尚未运行，无新准确率。

建议比较三组：原始最小任务说明（baseline）、通用零样例提示词（本稿候选）、机制定制提示词（现有v1/v2/v3）。v4九示例草案可作为定制提示词的后续探索，保留但不作为通用版主实验候选。

v3本身已列出时间、名单、否认等专项规则，应如实描述为经挑战集错误分析优化的任务定制提示词，不追溯性地更名为通用提示词。提示词改进的效果不能与模型原生能力等同。

固定提示词对全量使用属于必要条件；评估通用性还需冻结后在未用于改写提示词的新样本/新主题/基础集上验证。当前挑战集已多次用于开发，即便模板删除专项词汇，也不能重新变成独立测试集。原始数据、标签、旧提示词及分数均保留。

此候选在既有错误分析之后写成，不能称为预先注册的未见数据方案。它也保留了“缺少支持不等于反驳”这一通用语义原则；如果后续实验提升，仍需实际报告结果与推理预算，不能预设提升。
