# Prompt-v3全量实验结论

v3仅替换v2的一处名单范围规则，增加对相容场景的约束；否认规则、基础任务、输入位置和最终标签格式不变。885条挑战集全部新请求，不复用旧预测。生成参数与v2一致：qwen38-27b、temperature=0、关闭thinking、max_tokens4096、并发4。

## 结果

主跑756/885（85.42%），包含1条网络请求失败；0条解析失败、0条截断。该网络失败另存补跑后得到有效NEI回答，但金标准为SUPPORTS，仍判错。因此补齐后同为756/885，准确率未变，全部885条都有有效预测。原主跑与其评分保留。

下表比较全部有有效预测的v2网络补齐版和v3网络补齐版；v2原主跑749/885（84.63%）另记，不与750/885口径混写。

| 指标 | v2网络补齐 | v3网络补齐 |
| --- | ---: | ---: |
| 正确数 | 750/885 | 756/885 |
| Accuracy | 84.75% | 85.42% |
| Macro-F1 | 0.8172 | 0.8229 |
| NEI Recall | 71.29% | 72.47% |
| REFUTES Recall | 97.46% | 96.61% |
| SUPPORTS Recall | 97.08% | 97.66% |
| NEI误反条数 | 120 | 116 |

相对v2补齐版，32条纠正、26条退步，净增6条，Accuracy增加0.68个百分点。NEI召回增加1.18个百分点，SUPPORTS召回增加0.58个百分点，但REFUTES召回下降0.85个百分点。差值由原始数值计算。

## 名单范围是否改善

集合封闭（SETCLOSE）Accuracy从67/76（88.16%）升到70/76（92.11%），净增3条；NEI Recall从29/35（82.86%）升到32/35（91.43%）。这项定向修改在当前已观察数据上有小幅正向结果，恢复了v1的集合封闭整体准确率。不能仅因这一变化就认定已解决名单问题，仍有3条该类NEI误反。

## 得失分布

纠正32条：相似主体14、指代5、集合封闭4、唯一性4、时间预设2、时间范围2、否认1。退步26条：相似主体12、指代4、唯一性4、时间预设3、集合封闭1、时间范围1、否认1。

相似主体纠正与退步较多，净增仅2条；名单规则之外也存在输出变化，历史服务端波动与更长上下文都可能参与，不能把每条改判都归因于名单规则。时间预设整体准确率81.25%→80.56%，未改善。否认整体准确率保持98.96%，但具体样本并非全部相同。

金标准REFUTES→NEI新增1条：e_4fce433c09a10bb0。证据说Elena在2012年赢得一项地区业余赛事，陈述说Xabi赢得2012年女子德国业余足球锦标赛。v3认为主体及赛事范围不同不足以否定陈述，并对赛事名称的限制采取过度谨慎的解释。这涉及此前记录的主体/赛事范围与资格语义问题，需人工复核；本轮继续按原标计错，不修改标签加分。

剩余116条NEI误反：相似主体39、时间预设28、指代26、唯一性15、时间范围4、集合封闭3、否认1。主要瓶颈仍是主体、时间预设与指代。

## 调用与核验

主跑从manifest创建到结束约109.10分钟（含一次网络停止与续跑）。成功响应可见token1165997，其中输入982021、输出183976。失败请求尝试42次，含最终网络失败的3次尝试，主跑生成请求尝试数884+42=926次；另有一次请求级补跑。token数字不包含无法核实的失败尝试消耗。

5项离线测试通过；主跑和补跑均已独立复算。885个ID唯一，主跑全部evaluation_attempt=1，补跑仅选请求级network_error且attempt=2。冻结提示词、原始数据/标签、历史对照与代码哈希一致，输入未使用金标准或管理字段，全部输出密钥检查通过。

主跑见全量对照报告.md、summary.json与challenge.jsonl；请求级恢复见network-retry/。核验见work/prompt_v3_full_verification.json和work/prompt_v3_network_retry_verification.json。原Baseline、v1、v2及数据均未覆盖。

## 判断

v3的目标类别有所恢复，总分仅小幅改善，同时带来26条退步及REFUTES召回下降。当前证据不足以认定v3稳定优于v2，不宜仅凭6条净增直接替换默认版本。建议保留v2为参考版本，把v3作为范围规则的候选改动，使用同期对照和新的保留样本验证。

全部挑战数据此前已观察，属于开发性验证，非独立盲测；对照是历史结果，存在服务端输出波动。本轮未重跑900条基础集，也未训练LoRA。
