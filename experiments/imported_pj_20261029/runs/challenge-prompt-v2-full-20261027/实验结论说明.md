# 单次调用Prompt-v2全量实验结论

本轮使用此前草案原文，冻结后对挑战集885条全部重新请求。仅输入证据与陈述，不加金标准、机制或旧回答；没有第二阶段语义审查，没有训练。模型、温度、thinking开关、max_tokens4096和并发4与v1保持一致。

## 主跑结果：保留网络失败计分

主跑749/885（84.63%），相对v1净增73条、+8.25个百分点；相对原Baseline净增144条、+16.27个百分点；相对v1加独立审查净增55条、+6.21个百分点。差值均按未四舍五入的原始分数计算。

相对v1，94条纠正、21条退步；其中一条退步来自SUPPORTS样本的请求失败。另一个REFUTES请求失败样本在v1中本就没有判对。所有885条均保留主跑计分，未剔除失败。

## 网络失败补跑：单独保存与评分

主跑有两条网络超时在原配置的重试次数耗尽后仍失败，导致两次停止提交新请求；接口检查正常后分别从151与630条续跑，已完成记录没有重跑。主跑883条有效、2条请求失败、0条解析失败、0条截断。

主跑结束后，只按请求级network_error选择这两条，使用同一冻结提示词和参数单独补跑。两条都得到有效响应：一条REFUTES判对，一条SUPPORTS仍被判NEI。原始主跑和主评分保持不变，补跑原始记录及合并结果存入network-retry子目录。

补齐后为750/885（84.75%），Macro-F1 0.8172；NEI Recall 71.29%，REFUTES Recall 97.46%，SUPPORTS Recall 97.08%；全部885条均有有效预测。

补齐后相对v1：95条纠正、21条退步，净增74条、+8.36个百分点；相对原Baseline净增145条、+16.38个百分点；相对两阶段审查净增56条、+6.33个百分点。

因此，主报告使用保留两条网络失败的84.63%，网络恢复补充报告使用84.75%；两套口径不能混写，不能把补跑称为主跑零失败。

## 改善集中在哪里

主跑相对v1的94条纠正分布：否认45条、相似主体26条、唯一性7条、时间预设6条、指代5条、时间范围4条、集合封闭1条。

最明显的是否认机制：Accuracy 75.52%→98.96%，NEI Recall 51.04%→97.92%，原47条NEI误反降到2条。专项规则明确区分“有人否认P”与“证据证明P为假”，本轮该类结果显著改善；但v2同时调整了多条规则，未做逐条规则消融，不能严格分离每一条指令的因果贡献。

相似主体类也改善：NEI Recall 31.82%→54.55%。例如Melania与Maja的获奖样本，v2最终承认两人可以分别获奖，不能用妹妹获奖排除姐姐。原始回答仍有反复犹豫，说明规则执行还不稳定。

## 仍有哪些问题

NEI误反仍有120条：相似主体38、指代27、时间预设27、唯一性15、集合封闭6、时间范围5、否认2。指代与时间预设的改善仍较有限。

集合封闭类主跑Accuracy反而从92.11%降到88.16%，需检查模型是否过度放宽名单或范围限制。补跑后各机制完整指标见下表。

相对v1，补齐后的21条退步包括16条NEI→REFUTES、4条SUPPORTS→NEI、1条金标准REFUTES→NEI；不能据总分提高就称没有误伤。

金标准REFUTES→NEI的一条为e_c802018beea08dd8：证据只列Hegseth的两位搭档，但未给出陈述中的节目名称Fox & Friends Weekend，v2认为节目范围不足。这个样本与此前发现的节目范围争议有关，需人工复核；本轮仍按原标签计错，不修改金标准。补齐后REFUTES整体召回与v1相同，也不代表每条原本正确的反驳都被保住。

## 开销、核验与结论边界

主跑从冻结manifest到完成约115.50分钟，包含网络停止与续跑间隔。主跑成功响应可见token为1055490（输入868186、输出187304）；失败请求尝试38次，其中包括最终两条失败各自的3次尝试，生成请求尝试数为883+38=921次。网络补跑可见token：{"prompt_tokens": 2362, "total_tokens": 2952, "completion_tokens": 590}。失败尝试的服务端实际token或计费无法从成功响应完整核实。

v2虽然保持每样本一次语义判断，但提示词更长且部分回答很长，不能仅凭调用数减少就声称token成本更低。网络补跑是请求级恢复，未增加语义审查阶段。

5项离线测试通过；主跑及补跑均已独立复算。核验了885个唯一ID、主跑首次请求标记、冻结提示词、原数据与标签、历史对照哈希、输入管理字段隔离、逐条净变化及密钥不回显。原Baseline、v1和审查结果均未覆盖。

这轮说明，针对具体证据边界写清楚的单次提示词仍有明显开发集收益，不能仅从此前两阶段审查的有限收益就断言提示词空间已经很小。当前v2在这些已观察挑战样本上优于历史v1及历史两阶段审查。所有对照均为历史结果，仍含服务端波动；全部挑战数据已用于开发，不能当作独立盲测或泛化保证。基础集本轮未重跑，未训练LoRA。

产物：全量对照报告.md为主跑；本说明区分主跑与网络恢复；变化与残留样本.md附原始回答；network-retry/summary.json为补跑评分。核验分别见work/prompt_v2_full_verification.json及work/prompt_v2_network_retry_verification.json。
