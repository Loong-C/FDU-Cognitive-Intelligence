# 残余NEI过度反驳分析与下一步验证方案

## 当前事实

反驳门槛v1全量准确率为676/885（76.38%），NEI召回228/425（53.65%）。仍有194条NEI被判REFUTES，另有3条NEI被判SUPPORTS。剩余错误分布按机制为：

| 机制 | NEI误反条数 |
| --- | ---: |
| LOOKALIKE | 58 |
| DENIAL | 47 |
| AMBIGREF | 30 |
| PRESUP | 29 |
| UNIQUE | 18 |
| TEMPSCOPE | 8 |
| SETCLOSE | 4 |

前四类合计164/194（84.54%）。这里是按A方机制统计，不把机制名称当模型输入或线上路由条件。部分样本涉及此前发现的标注与证据范围争议；原始标签和主评分不修改。

## 优先方案 独立的反驳证据审查

冻结v1已有885条输出。所有初判REFUTES的309条进入二阶段，其余576条保持不变。入口只使用第一阶段预测，不使用真实标签，不只挑事后知道错的194条。二阶段模型输入仅为原证据和陈述，先不提供第一阶段标签或理由，减少复述原解释的倾向。该实验是冻结一阶段上的增量验证，不等同于整套流程端到端新复测。

审查任务拆成可检查的内容：

1. 拆解陈述中的主体、关系或事件、对象、时间、数量和范围。
2. 引用原文中据称能推出陈述不成立的最小证据片段；允许数值和时间推导，不要求原文出现否定句。
3. 列明推导需要的额外假设，尤其是唯一获奖、此前从未发生、全局完整名单、实体同一性、家族成员关系和发言可信性。
4. 尝试构造证据和陈述同时成立的具体情形，并核对该情形是否违反原文的明确约束。

例如，证据只说妹妹在2005年出版畅销小说，陈述说姐姐也在2005年出版畅销小说。两人各自出版一本不同小说的情形与证据相容，不能仅因主体不同就判反驳。若证据另有明确且适用范围正确的唯一性或否定限制，应据此检查该情形是否仍可成立。

审查结论不能只靠原文引句存在来决定：原文确实写了妹妹获奖，并不意味着该句能推出姐姐没获奖。需要核验从引句到反命题的逻辑关系。

建议先采用保守覆盖策略：确认完整陈述被证据支持才改SUPPORTS；确认支持和反驳都不能成立且有合格的相容情形时改NEI；反驳成立则保留REFUTES；审查结果含糊或内部冲突时保留原判、单列分歧。模型自身犹豫不等于任务中的信息不足。

## 零样本与对比示例分开做

先试结构化审查，不增加示例。若存在信号，再增加新建并核验的最小差异对比示例，另设实验臂。示例同时覆盖SUPPORTS、REFUTES、NEI，关键条件只改一处，如“在2020年获奖”与“在2020年首次获奖”。不要把所有缺失信息一律改NEI，也不使用旧测试错例的原文作为提示示例后宣称获得未见样本泛化。

同一模型在第二次调用时仍可能重复错误，独立输入或结构化字段不是正确性保证。相关研究观察到无外部反馈的自我纠错可能退步，因此必须保留一阶段对照并实测。

## 比较与验收

主对照应改为当前v1的76.38%，同时保留原Baseline68.36%供整体路线比较。所有结果仍以885条为分母，原标签不变。

关注194条原NEI误反中被纠正多少，以及第一阶段正确识别的115条真正反驳被改错多少；另报总Accuracy、Macro-F1、NEI Recall、REFUTES Precision/Recall、逐条转移、失败率、额外请求数量和耗时。补充基础能力回归检查；本方案尚未执行，不预报提升幅度。

## LoRA与偏好优化的后续位置

若审查能稳定识别错误，可把人工核验过的证据边界样本整理为短理由与标签的监督数据，以LoRA进行任务适配。包括明确支持、真正反驳和困难NEI，按group整组划分，争议样本先隔离。不能只训练194条NEI错例，否则可能形成过度输出NEI的偏差。

当有可靠的正确与错误回答对时，可再研究DPO；它是偏好训练目标，LoRA是参数适配方式，两者不互相替代。优先先做好监督数据与SFT对照，当前不直接启动训练。
