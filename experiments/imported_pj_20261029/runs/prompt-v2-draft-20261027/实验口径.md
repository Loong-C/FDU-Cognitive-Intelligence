# 单次调用提示词v2草案与实验口径

主比较：原始提示词Baseline vs 单次调用优化提示词Prompt-v2。两者均有证据、陈述、三类定义和输出要求；Baseline不含针对过度反驳的专项规则。Prompt-v1保留为中间版本。Prompt-v1+Audit属于两阶段方法，单列为额外审查实验，报告调用数及开销。

v2保留v1的系统角色、基本任务定义、证据/陈述占位符和最终标签格式，仅替换专项决策规则。把三项审查变为一次调用中的判断要求，不要求重复布尔字段。加强否认与事实、不同主体与排他关系、某次事件与唯一事件、局部与全局范围的区分，同时保留真正反驳和支持的判断条件。不加入原挑战错例或金标准作为示例。

建议评测时固定相同模型、temperature=0、关闭thinking、max_tokens=4096、相同数据和计分口径；对照尽量同期重新请求，历史结果另外保留。比较Accuracy、Macro-F1、NEI Recall、REFUTES Precision/Recall、输出失败率、逐条转移及token和耗时，不能只看NEI召回。

全部现有挑战数据已经观察，本轮若继续使用只能作为开发性比较，不能称独立盲测。最终结论需要新保留数据；基础能力也需回归检查。当前仅完成草案，没有启动API调用或生成v2分数。
