# V14：直接矛盾与简短依据的二元分解

本轮仅在**旧开发组**上探索，不承担独立显著性确认，也不改变正在执行的 V13 固定 NLI 确认。测试集不读取。

V13 旧开发初筛显示，显式包裹整句否定后询问蕴含，其反分支漏掉多数 REFUTES。这里比较两个宏观变化，不加入具体机制提示：

1. 保留原始命题，直接询问：是否在所有满足证据的情况中，整个命题都为假？使用实际 A/B token 概率。与 V13 正分支组合，共享阈值 0.10、0.25、0.50；两边均真或概率不可用时回退固定 NLI。
2. 分别判断整个命题是否必真、是否必假，每个分支先给一个简短依据，再输出 YES/NO 的约束 JSON。仅正分支 YES → S，仅反分支 YES → R，两者 NO → NEI；冲突或格式无效回退 NLI。另比较与 NLI 一致时保留 NLI、不一致时回退原 A27 的宏观门控。

模型、温度、seed、非思考开关与 V13 一致。所有输入仅含原始 claim/evidence。初筛复用服务器已有的基线、NLI 和二元正分支响应，新增 3 个分支 × 42 道旧题。标签仅在本地评估。

进入扩展的事前标准：挑战题至少比 NLI 多答对 2 题；基础题最多比 NLI 少对 1 题；满足与前轮相同的基线指标幅度限制。若没有候选达到，直接停止。若有，冻结一个候选后在另 126 道旧题上扩展，不再换阈值。所有结果仅能视为探索，不能当作新独立确认。

代码及协议先冻结于 `freeze.json`、`plan.json`。原始响应保存在 `outputs/server_v14/records`，两路并发。运行：

```powershell
$env:PYTHONDONTWRITEBYTECODE='1'
$env:PYTHONUTF8='1'
.venv\Scripts\python.exe -B -u -m ab_factcheck.semantic_binary_v14 pipeline
```
