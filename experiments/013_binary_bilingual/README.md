# V13：双蕴含阈值与双语指令

**状态：已完成并审计通过。** 最终保留单次英文 NLI。独立开发确认：基础 109/120 → 116/120，挑战 134/236 → 161/236；挑战增益 11.44 pp，单侧组置换 p≈0.0000124，通过冻结的主标准和指标幅度限制。完整数字与范围限制见 [RESULTS.md](RESULTS.md)。

本轮使用内网 `qwen38-27b`，温度 0、seed 42，明确关闭思考模式。所有模型请求仅含通用指令和开发题的 claim/evidence；标签只用于本地评估。测试集不读取。

二元方案分别查询 `E ⊨ C` 与 `E ⊨ ¬C`。通过实际 A/B token logprob 得到两个受约束选择概率，以同一个阈值判断是否蕴含：仅正分支通过为 SUPPORTS，仅反分支通过为 REFUTES，均不通过为 NOT ENOUGH INFO；均通过或概率不可用时回退到固定 NLI。候选阈值为 0.50、0.65、0.80、0.90。这些概率不是经过校准的事实置信度。

另一方向只将通用 NLI 指令换成中文，题目文本保持原样。比较直接中文 NLI，以及中英 NLI 一致时采用 NLI、否则回退 A27 的通用一致性门控。

先在 42 道已使用的开发题上运行三个新增分支，冻结一个候选（含阈值）；再扩展到另外 126 道已使用的开发题，只比较该候选和既有 NLI。控制组复用同一服务器 V11 的原始响应。按事前排序规则冻结最终方法后，才在 356 道保留题上重跑同期基线和方法。

保留题为基础集 120 题/14 个完整组、挑战集 236 题/38 个完整组。挑战集只剩六种机制，SETCLOSE 已没有未使用开发组；因此本轮不能声称独立确认覆盖全部七种机制。

主标准：挑战准确率至少增加 5 个百分点，单侧成对组置换检验 p ≤ 0.00625。幅度限制：基础准确率和 macro-F1 下降不超过 2 个百分点，挑战 macro-F1 不下降，各类召回下降不超过 5 个百分点。累计分配 alpha 为 0.04375，不拼接先前结果重选显著结论，幅度限制也不等于证明总体统计非劣。
