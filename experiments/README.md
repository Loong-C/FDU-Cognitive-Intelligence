# 实验记录

每个实验使用一个独立子目录，例如 `001_baseline/`。保留可复现的配置和简短记录：

- 模型名称与版本、提示词版本、推理或训练参数、随机种子。
- 使用的开发集版本，以及相对基线的改动。
- 基础能力集与核心挑战集各自的准确率、三类召回率。
- 核心挑战集的分机制结果、错误分析和结论。

日志、逐条预测和模型权重写入仓库根目录的 `outputs/`，不提交到 Git。
模型和方案选择使用开发集；最终测试时记录冻结配置与对应 Git 提交号。
