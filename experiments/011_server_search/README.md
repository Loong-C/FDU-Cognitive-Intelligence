# V11：使用内网 Qwen-27B 的宏观推理方法搜索

用户要求全面使用新增服务器 API，持续探索直至获得显著提升。新服务器为 `http://10.176.30.103:20027/v1`，模型名 `qwen38-27b`。服务端自报权重路径 Qwen3.8-27B-w8a8；不能将它与之前 Groq 后端视为逐位相同的部署。本轮所有基线和对照均重新在该服务器运行，不混用旧响应计分。

认证只从已授权的本机 Key 文件或环境变量读取；不写入请求记录。所有实验产物在仓库内。输入只包含开发集 claim/evidence；不读取测试集、不训练权重，不加入具体题型或关键词专用规则。

## 实测能力

`capabilities.json` 与 `choice_probe.json` 保存三个真实探针。已确认模型列表、`chat_template_kwargs.enable_thinking=false`、零可观察 reasoning tokens、严格 JSON Schema、`structured_outputs.choice` 以及 token logprobs。约束探针故意要求输出不允许的值，实际输出遵守约束。探针输入不含数据集样本。

## 候选

- A27 原始三分类，作为同期基线。
- V9 NLI、V10 保义复述、三候选关系核验，均以新服务器响应重测。
- 原命题的 A/B/C 强制选择，轮换三种标签与字母的对应关系，映射回语义标签后平均 token 概率。
- 整句否定命题的同样三种轮换；映回原命题时交换 SUPPORTS/REFUTES、保持 NEI。
- 原/否定共六个视角的概率平均。
- NLI、三候选核验、正向概率池、反向概率池的投票；平票优先 NLI。
- 正反 NLI 一致时接受 NLI，否则回退 A27。

概率来自约束解码下 A/B/C 首 token 的 logprobs，三者必须全部可见才使用；缺失记 INVALID，不伪造置信度。它们是受约束的模型选项概率，**不是校准后的事实正确率，也不用于计算统计显著性**。

所有候选保持非思考模式。简短依据和核验字段是显式任务输出。最多四个 HTTP 请求并行，每批最多四个；不通过多账号或收费套餐扩容。已有成功响应不重抽；不确定传输留下 inflight 并停止，最多对明确连接失败/重试状态做三次有界尝试。

## 冻结的分阶段评测

1. 历史 42 题做探索，重新运行 11 种底层调用，比较九种候选方法。
2. 仅前两名扩展至另外 126 道开发题，来自 42 个此前用过的开发组，每组按输入 ID hash 取三题。同期重跑 A27 和 NLI。此阶段仍用于选方法。
3. 冻结一个候选，确认集为事前选出的 **203 题、28 个完整新开发组**，每套每种机制两个组。排除全部旧 pilot、V5、V7、V8、V9 推理使用的组。V10 的未执行确认清单未当作已使用组；其行从未调用模型，抽样关系由冻结清单追溯。

`plan.json` 在任何本轮数据请求前冻结全部清单与选择规则；`freeze.json` 固定源码、数据、请求逻辑哈希。只根据探索和扩展分数选方法；确认后不重新挑选赢家。

## 事前统计成功标准

主指标是挑战集相对同期 A27 的准确率：**至少增加 5 个百分点，且按 group 成对交换的单侧精确置换检验 p ≤ 0.025**。相关变体按组处理，不假装每一题独立。

同时要求基础集准确率与宏 F1 各下降不超过 2 个百分点；挑战集宏 F1 不下降；两套数据每类召回率下降不超过 5 个百分点。这些是开发阶段的实际幅度限制，不是已证明统计非劣。

本次独立确认使用 alpha 0.025。若失败，后续新的独立确认最多依次使用 0.0125、0.00625……；不得反复在同一确认样本上选择方法直至显著。所有确认失败均保留，统计主指标和门槛不事后改写。

## 运行

```powershell
$env:PYTHONDONTWRITEBYTECODE='1'
$env:PYTHONUTF8='1'
.venv\Scripts\python.exe -B -m ab_factcheck.server_search_v11 prepare
.venv\Scripts\python.exe -B -u -m ab_factcheck.server_search_v11 pipeline
```

运行状态在 `outputs/server_v11/pipeline.json`。各阶段输出 `metrics.json`、`predictions.csv`；最终统计在本目录 `assessment.json`。所有原始响应和精确请求保存在 `outputs/server_v11/records`，不含认证头。
