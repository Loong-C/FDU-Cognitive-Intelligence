# 统一比较的结论与边界

2026-10-31 完成。使用同一原始 27B BF16 主干及推理实现，在相同基础 120 题、挑战 141 题上比较原始 A0、NLI、PJ v3，以及三个已选定 LoRA 适配器。
固定贪心、关闭 thinking、1024-token 上限和理由/Verdict 输出。两张同型号卡按题分片，每道题六个条件在同一个模型实例上轮换执行。
全部 1566 个评分单元经过服务器审计和本地独立复算；HTTP API 已恢复并通过短生成检查。

| 方法 | 基础准确率 | 挑战准确率 | 挑战 NEI 召回 | 挑战 REFUTES 召回 |
|---|---:|---:|---:|---:|
| 原始基线 | 96.67% | 71.63% | 41.18% | 100.00% |
| NLI | 95.83% | 74.47% | 48.53% | 100.00% |
| PJ v3 | 96.67% | 85.11% | 70.59% | 100.00% |
| LoRA 三种子均值 | 96.39% | 97.40% | 97.55% | 89.47% |

LoRA 挑战准确率三个种子分别为 97.87%、98.58%、95.74%，均值的样本标准差为 1.48 个百分点。
三种子没有当成三倍独立题目，也没有按本轮分数挑选最好种子。

## 本轮支持什么

- NLI 比共同基线挑战多对 4 题（+2.84pp），未达到预定至少 +5pp，组检验 Holm 校正 p=0.359375。
- PJ v3 比基线多对 19 题（+13.48pp），Holm p=0.0048828125，且各项下降幅度在允许范围内。本轮只有它通过全部预设门槛。
- LoRA 平均挑战增益 +25.77pp，Holm p≈0.00009155，准确率最高；但三个种子的反驳召回都从 19/19 降至 17/19，下降 10.53pp，超过允许的 5pp。因此完整成功标准未通过。
- PJ 相对 NLI 的挑战增益 +10.64pp，Holm p≈0.01440；LoRA 平均相对 PJ +12.29pp，Holm p≈0.01053。这些统计只描述这批历史开发数据，不是独立泛化证明。

若按照“挑战准确率改善，同时限制基础能力和各类召回下降”的既定目标，PJ v3 是本轮符合全部要求的候选。
若着眼于继续研发，LoRA 的总体准确率及 NEI 改善更突出，下一步应重点验证如何找回漏掉的真正反驳，而不是只进一步提高 NEI 倾向。

## 必须保留的限制

数据在项目历史中已有暴露：PJ 使用过全量数据，NLI 使用过开发数据，LoRA 的这批保留集旧成绩也已知。此次统一了比较条件，没有把它变成三方都未接触过的独立测试。
LoRA 训练理由为 AI 辅助标注，审核后 PRESUP 没有训练样本；原 V16 封存工程偏差继续披露。
NLI/PJ 的输出指令为本轮做了统一，结论针对统一后的版本，不等同于历史 API/JSON 原协议。

用户要求调整规模后又撤回，原 261 题方案恢复，缩减版未执行。随后一次显存不足导致再次中断，经许可暂停 API 并改用同型号 2/3 号卡恢复。
收到的显存失败记录按 INVALID 计错，未重跑覆盖；另有三次中断没有收到回答，保留原尝试记录且用量未知。收到的全部答案均有哈希追踪。
全体无效记录：基线 2，NLI 4，PJ 5（含 1 次显存失败），三个 LoRA 均为 0；这些均在原分母内计错。
生成耗时受暂停、设备和共享资源负载影响，报告中的时间是本轮观测，不能直接推广为部署性能保证。
