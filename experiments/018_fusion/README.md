# V18 三方法融合

本实验按用户确认的完整计划执行。所有数据来自已有冻结开发划分：训练 728 条、验证 259 条、比较 261 条；不增加题目，不修改金标，不纳入此前排除的训练组，不读取原测试集。它是历史开发比较，不能作为独立盲测泛化结论。

## 冻结设计

| 模型 | 提示词 | 配置数 |
|---|---|---:|
| 原始 BF16 27B | A0、NLI、PJ、NLI 后拼接 PJ | 4 |
| 原有 LoRA 42/43/44 | 各自上述四种提示词 | 12 |
| NLI/PJ/联合解释蒸馏，各三个种子 | 全部 A0 | 9 |

直接推理 25 配置 × 261 题 = 6525 次生成。另有 37 个多路配置：NLI+PJ，以及原有/三种蒸馏 LoRA 各种子的 NLI+LoRA、PJ+LoRA、NLI+PJ+LoRA。共 24 个方法族、62 个具体方法，开发比较评分单元为 16182；组件缓存复用，评分单元不等于物理调用次数。

多路初判全部有效且一致则直接返回；否则未微调模型用固定 NLI/PJ 复核提示裁决一次。候选匿名，按每个分区内题目哈希排序循环分配全部排列，使位置均衡。复核只接收原 evidence/claim 和候选输出，不使用标签、机制、模型身份或历史成绩。错误/无效组件进入既定复核，裁决无效计错，不增加轮次。

训练解释来自 NLI、PJ 各一次独立生成，以及结合二者的联合生成，共 2184 次教师调用。三套数据各自 728 条，所有解释逐条核查并附原文引用、决定和原因；最多 60 个英文词，金标固定。教师错误不直接用于监督。回退原审核理由也须明确记录。完成全部 2184 条审核后才能冻结训练数据。

九次训练分别从相同原始主干初始化，种子 42/43/44，每次三轮。保持 V16 的 rank 8、alpha 16、dropout .05、AdamW、1e-4 恒定学习率、有效 batch 16、目标投影、1536 序列上限；不得截断。新增训练数据只改变解释来源，输入均为 A0。最长样本/三标签前反向、保存重载、优化器与 RNG 恢复、关闭适配器恢复原模型均需完整 27B 烟测。

## 验证与报告

每轮 checkpoint 用 259 条验证题选择，排序沿用 V16；原有 LoRA 的 checkpoint 不改。九个选定 checkpoint 的 A0 验证响应与直接验证矩阵完全同输入、权重、计算身份时复用，计为同一个物理调用。其余直接对照本轮重新生成，不复用 V17 回答。

推荐方案只根据验证集冻结；验证报告必须通过独立审计后，执行器才允许进入 261 题完整比较。所有候选完整跑完，不根据成绩提前停止。

含 LoRA 的方法族按三个种子均值比较，幅度限制要求每个种子通过。相对共同 A0 基线，基础准确率下降最多 2pp、两集合各类召回下降最多 5pp；挑战准确率须高于原有 LoRA 均值。按组累计三倍种子均值正确数差，进行精确双侧符号置换，23 个方法族与原有 LoRA 比较进行 Holm 校正。基础/挑战分开报告，不拼接总分，不把三个种子当三倍题目。

验证候选先满足幅度限制和挑战改善，再按挑战准确率、基础准确率、挑战 Macro-F1、较少调用、较少 token、方法 ID 排序。没有融合候选达到条件则在既有 A0/NLI/PJ/原 LoRA 中按相同排序保留方案。部署种子预先固定为 42，另两个种子用于稳定性报告，不按评测分数挑种子。

报告给出每个种子及均值/标准差、各类/机制、无效输出、修正/损害、逻辑部署成本与实际去重调用成本。统计只描述历史开发数据。原标签歧义单独记录，不删题、不改主评分。PRESUP 无训练覆盖、AI 辅助标注以及 V16 封存偏差均继续披露。

## 运行与恢复

仅用已获准的 2/3 号卡。启动前核对原始权重、冻结输入和源码、API 身份及显存；服务守护器保留私有启动快照，在成功、失败或控制进程退出时清理本任务进程组并恢复 API。API 恢复须通过模型列表和短生成检查。

每次物理调用先写 inflight，后原子保存签名回答。已收到回答（包括失败）不重试、不覆盖。中断且未收到的尝试须显式归档并披露未知成本后恢复。训练最多重放未落 checkpoint 的七个更新，保留该成本限制。

执行入口和后续审核方式见 [RUNBOOK.md](RUNBOOK.md)。冻结文件、来源复制清单、运行状态各自留存，不自动提交或推送 Git。
